# Small Blog

## 文章中的讀音標註

在 Markdown 文章中使用：

```text
歡迎來到「c_pronouns("千穹日記", "ちそらにっき")」
```

第一個參數是文字，第二個是讀音；兩個參數都使用雙引號，遵循 JSON 字串轉義規則。程式碼區塊中的標記不會轉換，也可以直接使用 HTML 的 `<ruby>` 和 `<rt>`。文章預覽和字數只包含原文，不包含讀音。

標記由 `markdown-extensions.js` 的 Marked 擴充規則處理，不會執行文章中的程式碼。日後可以在 `extensions` 中新增其他明確定義的標記；該檔案必須在 Marked 之後、`blog.js` 之前載入。

## 文章中的日期計算

```text
c_time_counter("2008-03-27", "y")
c_time_counter("2008-03-27", "m")
c_time_counter("2008-03-27", "d")
```

使用東京日期計算與指定日期相距的完整年數、完整月數或總天數，未來日期也返回正數。月末和閏日以目標月份的最後一天作為週年或滿月日；日期須為有效的 `YYYY-MM-DD`，單位須為 `y`、`m` 或 `d`。結果在載入預覽或打開文章時更新。

## 依模式切換文字

```text
c_secret("男", "女")
```

第一個參數在預設模式顯示，第二個在隱藏模式顯示；切換模式時文章和預覽會立即更新。參數使用雙引號並遵循 JSON 字串轉義規則；程式碼區塊中的標記不會轉換。

`c_secret` 的文字中可以嵌套已支援的指令，例如：

```text
c_secret("c_pronouns("Terry", "テリー")", "c_pronouns("天音", "あまね")")
```

也可以使用 `\"` 轉義內層引號。最多支援 10 層 `c_secret`。

隱藏模式只改變顯示，文章原始檔仍可被訪客讀取，不能用於保護私密資訊。
